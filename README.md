# Cozy Seasons

A cozy pixel-art life sim. Move into a little house in Willowbrook Village, care for your pets,
garden, cook, and live through spring, summer, a long golden autumn, and winter.

## Run

ES modules need a local server:
python -m http.server 8000 (or: npx serve)
Open http://localhost:8000

## Controls

WASD/Arrows move · E interact · I inventory · P phone · M map · Q quests · Esc pause
